🎯 Objetivo principal

La materia de Programación IV tiene como objetivo principal desarrollar conocimientos y habilidades para la creación de aplicaciones móviles, aplicando diferentes tecnologías, lenguajes y frameworks utilizados actualmente en el desarrollo de software.

Durante el desarrollo de la materia se trabajará con tecnologías orientadas al desarrollo de aplicaciones móviles, considerando tanto herramientas multiplataforma como tecnologías nativas.

📱 Tecnologías utilizadas
Node.js

Node.js es un entorno de ejecución de JavaScript que permite ejecutar código fuera del navegador. Se utiliza principalmente para desarrollar aplicaciones del lado del servidor, APIs y servicios backend.

En proyectos móviles puede utilizarse para crear el backend que proporciona datos y servicios a una aplicación móvil.

React Native

React Native es un framework desarrollado por Meta que permite crear aplicaciones móviles para Android e iOS utilizando JavaScript y React.

Su principal ventaja es la posibilidad de compartir gran parte del código entre diferentes plataformas, facilitando el desarrollo de aplicaciones multiplataforma.

Dart

Dart es un lenguaje de programación desarrollado por Google y utilizado principalmente junto con Flutter.

Es un lenguaje orientado a objetos y está diseñado para crear aplicaciones rápidas y multiplataforma. Su sintaxis es similar a otros lenguajes modernos, lo que facilita su aprendizaje.

Flutter

Flutter es un framework de desarrollo de aplicaciones multiplataforma creado por Google. Utiliza el lenguaje Dart y permite desarrollar aplicaciones para:

Android

iOS

Web

Windows

macOS

Linux

Flutter utiliza un sistema de widgets para construir las interfaces gráficas, permitiendo crear diseños modernos y reutilizables.

Kotlin

Kotlin es un lenguaje de programación moderno desarrollado por JetBrains. Es uno de los principales lenguajes utilizados para el desarrollo nativo de aplicaciones Android.

Kotlin permite desarrollar aplicaciones seguras, modernas y eficientes, y cuenta con integración con las herramientas oficiales del ecosistema Android.

🚀 Objetivo del proyecto

El proyecto tiene como finalidad aplicar los conocimientos adquiridos durante Programación IV mediante el desarrollo de aplicaciones móviles funcionales, utilizando diferentes herramientas y tecnologías.

Se busca que el estudiante pueda comprender el ciclo completo de desarrollo de una aplicación, desde el diseño de la interfaz hasta la implementación de funcionalidades, conexión con servicios y preparación de la aplicación para su ejecución.

📌 Conclusión

Programación IV busca fortalecer las competencias de desarrollo de software mediante la creación de aplicaciones móviles. El uso de tecnologías como React Native, Flutter, Dart y Kotlin, complementadas con herramientas backend como Node.js, permite conocer diferentes enfoques para solucionar problemas y desarrollar aplicaciones modernas.

El aprendizaje de estas tecnologías proporciona una base para continuar con proyectos de mayor complejidad dentro del desarrollo móvil y de software.
